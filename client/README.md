# SplitEase — client

React 19 + TypeScript single-page app, built with Vite.

```bash
npm install
cp .env.example .env   # set VITE_API_URL and the currency
npm run dev            # http://localhost:5173
npm run build          # type-check + production build
npm run lint
```

See the [main README](../README.md) for the full project overview and setup.
